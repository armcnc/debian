# LubanCat 5 Debian 12 PREEMPT_RT 定制说明

## 概述

本文档说明如何在 LubanCat 5 平台上将 Debian 12 系统定制为适用于实时控制场景的 PREEMPT_RT 环境。涵盖系统源配置、基础环境初始化、用户账号调整、设备标识修改、实时内核安装以及桌面交互优化。

适用平台：LubanCat 5

适用系统：Debian 12

目标内核：Linux 6.1.99-rt36

> 说明：脚本中包含多次系统重启。建议按照章节顺序执行，并在每次重启后确认系统已正常启动再继续下一步操作。

## 1. 适用场景

本定制流程适用于以下场景：

- 需要在工业控制、伺服控制或实时任务环境中运行 Debian 12
- 需要将默认系统账户统一为 `debian`
- 需要将设备命名统一为 `armcnc`
- 需要启用 PREEMPT_RT 实时内核以降低系统调度延迟
- 需要记录网卡与 EtherCAT 设备的 MAC 地址，便于设备识别和部署管理

## 2. 执行前提

在执行脚本前，请确认：

- 设备已启动 Debian 12 图形化桌面环境
- 网络连接正常，能够访问外部软件源
- 当前用户具备 `sudo` 权限
- 已备份关键系统配置文件，例如 `/etc/passwd`、`/etc/shadow`、`/etc/group` 等
- 已准备好终端用于观察脚本执行过程和重启后的状态

## 3. 系统基础配置

### 3.1 配置软件源并更新系统

脚本首先安装必要的依赖工具，并导入 Embedfire 仓库密钥：

```bash
sudo apt install curl gnupg ca-certificates
curl -fsSL https://Embedfire.github.io/keyfile -o /tmp/embedfire-keyfile
sudo install -d -m 0755 /etc/apt/keyrings
sudo gpg --batch --yes --dearmor -o /etc/apt/keyrings/embedfire.gpg /tmp/embedfire-keyfile
sudo chmod 0644 /etc/apt/keyrings/embedfire.gpg
```

随后更新软件包列表并升级系统基础组件：

```bash
sudo apt -y update && sudo apt -y upgrade
```

### 3.2 配置系统语言环境

脚本启用 `en_US.UTF-8` 语言环境：

```bash
sudo sed -i 's/^# *en_US.UTF-8 UTF-8/en_US.UTF-8 UTF-8/' /etc/locale.gen
sudo locale-gen
sudo update-locale --reset LANG=en_US.UTF-8 LANGUAGE=en_US:en
```

完成后重启系统：

```bash
sudo reboot
```

## 4. 用户账号与系统命名

### 4.1 创建临时管理员账号

脚本创建 `tempadmin` 用户并将其加入 `sudo` 组：

```bash
sudo adduser tempadmin
sudo usermod -aG sudo tempadmin
```

随后重启系统以便确认该用户配置生效。

### 4.2 将默认用户 `cat` 改为 `debian`

脚本首先备份与用户管理相关的关键配置：

```bash
sudo mkdir -p /root/cat-rename-backup
sudo cp -a /etc/passwd /etc/shadow /etc/group /etc/gshadow /etc/gdm3/daemon.conf /root/cat-rename-backup/
```

随后停止 GDM 服务并终止原有用户会话：

```bash
sudo systemctl stop gdm3
sudo loginctl terminate-user cat
```

检查当前系统中是否已有 `debian` 用户和 `/home/debian` 目录：

```bash
pgrep -a -u 1000
getent passwd debian
getent group debian
ls -ld /home/debian
```

完成确认后执行用户名重命名：

```bash
sudo usermod -l debian cat
sudo groupmod -n debian cat
sudo usermod -d /home/debian -m debian
sudo usermod -c debian debian
```

并同步更新 GDM 自动登录配置：

```bash
sudo sed -i -E 's/^([[:space:]]*AutomaticLogin[[:space:]]*=[[:space:]]*)cat[[:space:]]*$/\1debian/' /etc/gdm3/daemon.conf
```

这样系统将默认登录至 `debian` 用户，并保持用户主目录与系统配置一致。

### 4.3 修改设备主机名与 hosts 映射

脚本将默认主机名从 `lubancat` 修改为 `armcnc`：

```bash
sudo sed -i 's/^lubancat$/armcnc/' /etc/hostname
sudo sed -i "s/\blubancat\b/armcnc/g" /etc/hosts
```

### 4.4 设置默认用户密码

脚本将 `debian` 用户密码设置为默认值 `debian`：

```bash
echo "debian:debian" | sudo chpasswd
```

### 4.5 清理临时管理员与备份文件

脚本删除临时管理员账户：

```bash
sudo deluser --remove-home tempadmin
```

并清理用户重命名的备份目录：

```bash
sudo ls -la /root/cat-rename-backup
sudo rm -r -- /root/cat-rename-backup
```

随后重启系统，完成默认用户切换。

## 5. SSH、系统标识与登录信息

### 5.1 配置 SSH 保活参数

脚本修改 SSH 服务的保活参数，以减少长连接断开导致的远程管理异常：

```bash
sudo sed -i -e 's/^[[:space:]#]*ClientAliveInterval[[:space:]].*/ClientAliveInterval 60/' \
            -e 's/^[[:space:]#]*ClientAliveCountMax[[:space:]].*/ClientAliveCountMax 3/' /etc/ssh/sshd_config
sudo sshd -t && sudo systemctl reload ssh
```

### 5.2 自定义登录欢迎信息

脚本创建 `/etc/update-motd.d/00-header` 和 `/etc/update-motd.d/10-help-text`，用于在终端登录时显示统一的系统信息与企业链接。

```bash
sudo tee /etc/update-motd.d/00-header > /dev/null <<'EOF'
#!/bin/sh

[ -r /etc/lsb-release ] && . /etc/lsb-release

printf '\n\033[90m'
cat <<'BANNER'
     _      ____    __  __    ____   _   _    ____
    / \    |  _ \  |  \/  |  / ___| | \ | |  / ___|
   / _ \   | |_) | | |\/| | | |     |  \| | | |
  / ___ \  |  _ <  | |  | | | |___  | |\  | | |___
 /_/   \_\ |_| \_\ |_|  |_|  \____| |_| \_|  \____|

BANNER
printf '\033[0m\n'

if [ -z "$DISTRIB_DESCRIPTION" ] && [ -x /usr/bin/lsb_release ]; then
    DISTRIB_DESCRIPTION=$(lsb_release -s -d)
fi

printf 'Welcome to %s (%s %s %s)\n\n' \
    "${DISTRIB_DESCRIPTION:-Debian GNU/Linux}" \
    "$(uname -o)" "$(uname -r)" "$(uname -m)"
EOF
```

```bash
sudo tee /etc/update-motd.d/10-help-text > /dev/null <<'EOF'
#!/bin/bash
#
#    10-help-text - print the help text associated with the distro

printf " * Documentation:  http://doc.armcnc.org\n"
printf " * Management:     http://www.armcnc.org\n"

if [ -e /boot/boot_init ];then
    source /etc/init.d/boot_init.sh > /dev/null 2>&1
fi

printf "\n"
EOF
```

通过该配置，系统登录后将直接展示设备品牌信息、内核版本以及帮助入口。

## 6. PREEMPT_RT 实时内核安装

### 6.1 卸载旧内核并安装实时内核

脚本会先移除旧版本内核：

```bash
sudo apt remove linux-headers-6.1.99-rk3588 linux-image-6.1.99-rk3588
```

随后安装对应的 PREEMPT_RT 内核包：

```bash
sudo dpkg -i linux-image-6.1.99-rt36-rk3588_6.1.99-rt36-rk3588-9_arm64.deb \
             linux-headers-6.1.99-rt36-rk3588_6.1.99-rt36-rk3588-9_arm64.deb
```

此处采用的内核版本为 `6.1.99-rt36`，用于提供更低的调度延迟和更稳定的实时响应能力。

### 6.2 配置 CPU 隔离参数

脚本会修改启动参数文件 `/boot/uEnv/uEnvLubanCat5-V2.txt`，将 CPU 6 和 7 配置为实时任务专用核心：

```bash
sudo sed -i -e 's/isolcpus=7\b/isolcpus=6,7/g' \
            -e 's/nohz_full=7\b/nohz_full=6,7/g' \
            -e 's/rcu_nocbs=7\b/rcu_nocbs=6,7/g' /boot/uEnv/uEnvLubanCat5-V2.txt
```

确认命令行参数：

```bash
grep '^cmdline=' /boot/uEnv/uEnvLubanCat5-V2.txt
```

此设置可将指定核隔离出通用调度域，优先供实时线程使用，从而降低抖动并提高控制任务稳定性。

## 7. 网络与 EtherCAT 设备识别

脚本会在用户目录创建统一的设备信息目录 `~/.armcnc`，并记录网卡与 EtherCAT 相关的 MAC 地址：

```bash
sudo mkdir -p ~/.armcnc
ifconfig -a | awk '
/^[^[:space:]]/ { iface=$1; sub(/:$/, "", iface) }
$1 == "ether" { print iface, $2 }
' | sudo tee ~/.armcnc/mac-addresses
```

提取以太网接口地址：

```bash
mac_addresses=$(awk '$1 == "eth0" { print $2; exit }' ~/.armcnc/mac-addresses)
echo "$mac_addresses"
```

脚本进一步清理并汇总 EtherCAT 接口地址：

```bash
{
    for dev in /sys/class/net/*; do
        [ -r "$dev/type" ] || continue
        [ "$(cat "$dev/type")" = "1" ] || continue
        printf '%s %s\n' "${dev##*/}" "$(cat "$dev/address")"
    done

    if command -v ethercat >/dev/null 2>&1; then
        sudo ethercat master 2>/dev/null | awk '
            $1 == "Main:" || $1 == "Backup:" {
                if ($2 ~ /^([[:xdigit:]]{2}:){5}[[:xdigit:]]{2}$/)
                    print "ethercat", tolower($2)
            }
        '
    fi

    for node in /proc/device-tree/ethernet@*; do
        [ -r "$node/compatible" ] || continue
        tr '\0' '\n' < "$node/compatible" | grep -q ethercat || continue

        for prop in mac-address local-mac-address; do
            [ -r "$node/$prop" ] || continue

            mac=$(od -An -v -tx1 "$node/$prop" | awk '
                {
                    for (i = 1; i <= NF; i++) bytes[++n] = $i
                }
                END {
                    if (n == 6)
                        printf "%s:%s:%s:%s:%s:%s",
                            bytes[1], bytes[2], bytes[3],
                            bytes[4], bytes[5], bytes[6]
                }
            ')

            case "$mac" in
                ""|00:00:00:00:00:00|ff:ff:ff:ff:ff:ff) continue ;;
            esac

            printf 'ethercat %s\n' "$mac"
            break
        done
    done
} | awk '!seen[tolower($2)]++' | sudo tee ~/.armcnc/mac-addresses
```

提取 EtherCAT 地址：

```bash
ethercat_mac_addresses=$(awk '$1 == "ethercat" { print $2; exit }' ~/.armcnc/mac-addresses)
echo "$ethercat_mac_addresses"
```

该文件便于在部署时进行设备标识、网络确认和 EtherCAT 节点绑定。

## 8. GNOME 桌面优化

脚本通过 GNOME Shell 扩展禁用登录后的 Overview，避免用户在自动登录时直接进入应用概览界面：

```bash
shell_pid=$(pgrep -u "$(id -u)" -x gnome-shell | head -n 1)
desktop_bus=$(sudo cat "/proc/$shell_pid/environ" \
    | tr '\0' '\n' \
    | sed -n 's/^DBUS_SESSION_BUS_ADDRESS=//p')

export DBUS_SESSION_BUS_ADDRESS="$desktop_bus"

mkdir -p ~/.local/share/gnome-shell/extensions/no-overview@armcnc
```

创建扩展的 `metadata.json`：

```json
{
    "uuid": "no-overview@armcnc",
    "name": "Start on Desktop",
    "description": "Disable the overview at login",
    "shell-version": ["43"],
    "version": 1
}
```

创建扩展逻辑：

```javascript
const Main = imports.ui.main;
const GLib = imports.gi.GLib;

let startupId = 0;
let timeoutId = 0;
let previousValue;

function init() {}

function hideOverview() {
    timeoutId = GLib.timeout_add(GLib.PRIORITY_DEFAULT, 1000, () => {
        Main.overview.hide();
        timeoutId = 0;
        return GLib.SOURCE_REMOVE;
    });
}

function enable() {
    previousValue = Main.layoutManager.startInOverview;
    Main.layoutManager.startInOverview = false;

    if (Main.layoutManager._startingUp) {
        startupId = Main.layoutManager.connect("startup-complete", () => {
            Main.layoutManager.disconnect(startupId);
            startupId = 0;
            hideOverview();
        });
    } else {
        hideOverview();
    }
}

function disable() {
    if (startupId) {
        Main.layoutManager.disconnect(startupId);
        startupId = 0;
    }
    if (timeoutId) {
        GLib.source_remove(timeoutId);
        timeoutId = 0;
    }
    Main.layoutManager.startInOverview = previousValue;
}
```

最终启用扩展：

```bash
gsettings set org.gnome.shell disable-user-extensions false
gsettings set org.gnome.shell enabled-extensions "['no-overview@armcnc']"
```

这样登录后系统会直接进入桌面环境，适合工业控制设备的现场操作场景。

## 9. 安全与清理

脚本末尾执行：

```bash
history -c && history -w && rm -rf .bash_history && exit
```

或：

```bash
history -c && history -w && rm -rf .bash_history && sudo reboot
```

该步骤用于清理执行痕迹，并减少用户命令历史被泄露的风险。

## 10. 注意事项

- 脚本会多次执行重启，建议在每次重启后等待系统完全启动后再继续下一步。
- 用户名重命名与 GDM 自动登录修改属于高风险操作，请在执行前确认系统备份已完成。
- 如遇登录异常，请检查以下文件：
    - `/etc/gdm3/daemon.conf`
    - `/etc/passwd`
    - `/etc/group`
    - `/home/debian`
- 实时内核和 CPU 隔离参数应结合实际控制任务进行验证，确保不会影响设备的其他功能需求。

## 11. 总结

本定制流程将 LubanCat 5 上的 Debian 12 系统转换为具有更稳定实时性能的部署环境。通过统一设备命名、替换默认用户名、更新主机标识、安装 PREEMPT_RT 内核、配置实时 CPU 隔离和优化 GNOME 登录体验，系统能够更好地适配工业控制和实时任务场景。
