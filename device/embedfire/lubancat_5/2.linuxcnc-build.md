# LubanCat 5 LinuxCNC 编译与安装说明

## 概述

本文档说明如何在 LubanCat 5 平台上基于 Debian 12 PREEMPT_RT 系统编译并安装 LinuxCNC 2.9.10 源码包。用于完成 LinuxCNC 源码拉取、构建依赖准备、实时环境配置、二进制编译、Debian 包构建以及最终安装。

适用平台：LubanCat 5

适用系统：Debian 12（已完成 PREEMPT_RT 定制）

目标版本：LinuxCNC v2.9.10

> 说明：本流程需要较长时间编译，且在部分阶段会要求设置实时 CPU 频率和运行 latency 测试。建议在稳定供电和网络连接正常的环境中进行。

## 1. 适用场景

本流程适用于以下场景：

- 需要在 LubanCat 5 上编译 LinuxCNC 用户空间版本
- 需要将 LinuxCNC 作为 CNC/伺服控制软件栈接入实时系统
- 需要生成 Debian 安装包以便统一部署和版本管理
- 需要验证系统在实时环境下的 Latency 性能表现

## 2. 执行前提

在执行脚本前，请确认：

- 已完成 `LubanCat 5 Debian 12 PREEMPT_RT` 的系统定制
- 设备已正常启动到 Debian 12 图形化环境或可用命令行终端
- 已具备 `sudo` 权限
- 网络可正常访问 GitHub 或可替换的镜像源
- 设备已配置为实时环境，且 CPU 6 / 7 可用于性能测试

## 3. 编译前准备

### 3.1 安装基础构建依赖

脚本首先安装 LinuxCNC 所需的基本构建工具：

```bash
sudo apt update && sudo apt install git build-essential dpkg-dev fakeroot
```

这些组件包括：

- `git`：用于下载源码
- `build-essential`：C/C++ 编译工具链
- `dpkg-dev`：用于 Debian 包构建工具集
- `fakeroot`：用于创建 Debian 软件包时模拟 root 权限

### 3.2 拉取 LinuxCNC 源码

脚本从 GitHub 拉取 LinuxCNC 源码，并切换到 `v2.9.10` 分支：

```bash
git clone --branch v2.9.10 https://github.com/LinuxCNC/linuxcnc.git linuxcnc
```

备用镜像地址：

```bash
git clone --branch v2.9.10 https://gh-proxy.com/https://github.com/LinuxCNC/linuxcnc.git linuxcnc
# 或
git clone --branch v2.9.10 https://ghclone.com/https://github.com/LinuxCNC/linuxcnc.git linuxcnc
```

如果直接 GitHub 访问受限，可根据当前网络环境选择可用备用镜像地址。

### 3.3 记录源码提交信息

脚本进入源码目录后记录当前提交哈希：

```bash
cd linuxcnc
git rev-parse HEAD | tee ../source-commit.txt
```

该文件可用于后续版本溯源和构建记录保存。

## 4. LinuxCNC 源码构建

### 4.1 初始化 Debian 构建环境

在源码根目录执行：

```bash
./debian/configure uspace
```

此命令用于根据 Debian 环境生成所需的构建配置，准备后续软件包编译。

### 4.2 安装 Xvfb 及相关运行依赖

脚本解除对 `xserver-common` 的锁定，并安装 Xvfb：

```bash
sudo apt-mark unhold xserver-common
sudo apt-get install xvfb xserver-common
sudo apt-mark hold xserver-common
```

这一步的目的是满足 LinuxCNC 在用户空间构建过程中对图形环境相关依赖的需要。

### 4.3 安装编译所需依赖

脚本在源码目录中执行：

```bash
sudo apt-get build-dep .
```

这会自动根据 Debian package metadata 安装 LinuxCNC 的构建依赖，避免手动逐个补齐缺失库。

### 4.4 配置与编译 LinuxCNC 二进制

进入 `src` 目录：

```bash
cd src
./autogen.sh
./configure --with-realtime=uspace
make -j6
sudo make setuid
```

这里完成了以下动作：

- 生成 `configure` 脚本
- 配置以 user-space 实时方式编译
- 编译 LinuxCNC 主程序
- 设置 setuid，以便可执行文件具备所需权限

### 4.5 设置实时 CPU 频率与性能模式

在源码目录外回到 `~/linuxcnc` 后，执行：

```bash
source scripts/rip-environment
```

随后将 CPU 6 和 7 设置为 `performance` 模式：

```bash
for cpu in 6 7; do
    echo performance | sudo tee /sys/devices/system/cpu/cpu${cpu}/cpufreq/scaling_governor
done
```

这一步用于提升实时线程在控制任务中的稳定性和可预测性。

接着运行时延测试工具：

```bash
latency-histogram --base 125000 --servo 125000 --show --verbose
```

该命令可帮助评估系统在实时工作负载下的 latency 表现，便于判断系统是否满足控制需求。

## 5. 构建 Debian 安装包

### 5.1 清理旧编译产物

在构建 Debian 软件包前清理之前的构建结果：

```bash
cd ~/linuxcnc/src
make clean
```

返回源码根目录：

```bash
cd ~/linuxcnc
./debian/configure uspace no-docs
```

其中 `no-docs` 参数表示构建时不包含文档内容，适合减少构建时间和软件包体积。

### 5.2 检查依赖完整性

执行：

```bash
dpkg-checkbuilddeps
```

该命令用于验证 Debian 包构建所需依赖是否全部就绪。

### 5.3 生成 Debian 包

脚本执行：

```bash
dpkg-buildpackage -b -us -uc -j6
```

这里使用 `-j6` 进行并行编译，提升构建效率。

构建完成后，通常会得到：

- `linuxcnc-uspace_2.9.10_arm64.deb`
- `linuxcnc-uspace-dev_2.9.10_arm64.deb`

## 6. 安装 LinuxCNC

### 6.1 处理 `io` 二进制冲突

脚本会将 `/usr/bin/io` 进行 diversion，避免与 `linuxcnc-uspace` 提供的 `io.rktoolkit` 版本冲突：

```bash
sudo dpkg-divert --package linuxcnc-uspace \
  --add --rename \
  --divert /usr/bin/io.rktoolkit \
  /usr/bin/io
```

这一步用于保留系统中原有 `io` 入口，防止二进制命名冲突。

### 6.2 安装构建产物

脚本执行：

```bash
sudo apt install ./linuxcnc-uspace_2.9.10_arm64.deb ./linuxcnc-uspace-dev_2.9.10_arm64.deb
```

安装后，LinuxCNC 用户空间版本和对应开发文件即可使用于后续应用开发或运行环境。

## 7. 关键注意事项

### 7.1 构建时间与资源要求

LinuxCNC 源码编译需要较长时间，且 CPU 和内存占用相对较高。建议在系统资源充足时执行，并确保：

- 设备持续供电稳定
- 终端不被非正常退出打断
- 网络连接稳定，避免中断拉取源码或安装依赖

### 7.2 实时性能验证

运行 `latency-histogram` 时，应结合现场控制任务进行观察，以确认：

- 任务调度稳定
- latency 是否满足控制要求
- 是否存在明显抖动或峰值超出预期

### 7.3 版本管理

脚本会将源码的当前提交记录写入 `../source-commit.txt`，建议保留此文件，便于：

- 跟踪编译版本
- 复现环境
- 排查特定提交引入的问题

## 8. 运行建议

1. 确保已完成实时内核定制和 CPU 隔离配置后再执行 LinuxCNC 编译。
2. 优先在 Debian 12+PREEMPT_RT 环境中构建，以保证与目标运行环境一致。
3. 如遇编译依赖缺失，重新执行 `sudo apt-get build-dep .`。
4. 若峰值延迟偏高，可重新检查 CPU governor、实时内核参数和系统负载情况。
5. 对于批量部署场景，建议将生成的 `.deb` 包保存在版本仓库或固件镜像中，便于后续重复安装。

## 9. 总结

该脚本提供了一套完整的 LinuxCNC 在 LubanCat 5 平台上的编译与安装流程，覆盖了源码拉取、依赖准备、实时环境配置、源码编译、Debian 包构建以及最终安装。通过将 LinuxCNC 构建到与实时内核一致的系统环境中，可以更稳定地满足 CNC 控制和伺服任务对低延迟、可预测性和部署一致性的要求。
